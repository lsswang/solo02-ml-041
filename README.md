# Short profile evidence and coding DNA

The synthetic starter has a working equal-length, gap-free protein profile
analyzer and a per-position consensus/first-codon encoder. Run `python demo.py`.
It uses only the declared A/C/D/E amino acids and does not download any model.

These ordinary entry points do not handle insertion/deletion uncertainty or
global DNA constraints. The task text defines the requested new semantics.
No expression, fitness or laboratory outcome is modeled or claimed.
